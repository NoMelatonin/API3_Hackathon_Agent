# Local demo fonts

DM Sans and Manrope are self-hosted to preserve the V1 demo typography without a runtime request to Google Fonts. Both are distributed under the included SIL Open Font License 1.1 files.

Downloaded on 2026-10-31 from the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/dmsans — `DMSans[opsz,wght].ttf`, `OFL.txt`
- https://github.com/google/fonts/tree/main/ofl/manrope — `Manrope[wght].ttf`, `OFL.txt`
